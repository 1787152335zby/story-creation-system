# 创作工作台重设计 · 设计规范

> 版本：v1.0
> 状态：设计定稿 · 待实现
> 原型：`workspace-v6.html`

---

## 一、设计目标

将当前 Workspace（单阶段查看器 + 左侧时间线）重构为**创作驾驶舱**，解决三个核心问题：

1. **不可浏览** — 只能看当前阶段内容，看不到完整产物
2. **不可并行** — 生成时无法浏览其他文件
3. **审批无仪式** — 版本选择、修改意见操作散落在小按钮中

---

## 二、布局架构

```
┌──────────────────────────────────────────────────────┐ 44px
│ 📖 项目名  [🎬 完整剧本 · 2/6]  产出 8文件 · 1,820字  │ 顶部控制栏
│                                          [▶ 继续创作] │
├──────────────────────────────────┬───────────────────┤
│                                  │                    │
│         内容区（占满）             │  产物抽屉（按需滑出）│
│   - 仪表盘（空闲）                │  Ctrl+B 切换       │
│   - 流式生成（生成中）             │  右侧 280px        │
│   - 产物查看（选中文件）           │                    │
│                                  │                    │
├──────────────────────────────────┴───────────────────┤ 可变高度
│  🎯 审批面板 — 版本对比 A/B | 混搭 | [确认] [修改]     │ 审批面板
├──────────────────────────────────────────────────────┤ 38px
│ ●大纲  ●剧情  ●剧本  ○角色  ○分镜  ○生图   [浏览文件] │ 底部阶段导航
└──────────────────────────────────────────────────────┘
```

### 三层结构

| 层 | 高度 | 内容 | 是否可折叠 |
|---|---|---|---|
| 顶部控制栏 | 44px | logo、项目名、阶段胶囊、产出统计、操作按钮 | 否 |
| 内容区 | 剩余空间 | 仪表盘 / 流式生成 / 产物内容 | 否 |
| 审批面板 | 可变 (60-200px) | 版本选择 A/B、混搭编辑器、确认/修改/跳过 | 是（无审批时隐藏） |
| 底部阶段导航 | 38px | 6 个阶段标签 + 快捷操作 | 否 |

## 三、核心交互

### 3.1 三种状态，三种界面

| 状态 | 顶部 | 内容区 | 审批面板 | 底部 |
|---|---|---|---|---|
| **空闲（仪表盘）** | 阶段信息 + 统计 | 6 张阶段卡片 + 进度条 | 隐藏 | 阶段标签 |
| **生成中** | 阶段胶囊更新 + "⏸ 生成中" | 流式文字实时滚动 | 隐藏 | "📋 浏览文件" / "✕ 取消" |
| **审批中** | 阶段信息 | 显示产物内容 | **弹出**：版本对比 + 操作按钮 | 阶段标签 |

### 3.2 仪表盘（空闲状态）

- 6 张阶段卡片，3×2 网格
- 已完成：绿色边框 + "已完成"标签
- 进行中：紫色边框 + "进行中"标签 + 可点击
- 待开始：灰色 + 半透明 + 不可点击
- 每张卡片显示：图标、阶段名、状态标签、内容摘要（一行）、文件数和字数
- 下方进度条区：各阶段产出统计（文件数 + 字数）
- 点击卡片 → 打开该阶段第一个产物

### 3.3 流式生成

- 内容区顶部出现黄色脉动横幅，显示：
  - 旋转动画 + "正在生成 完整剧本 · 第X集"
  - 实时字数、生成速度
  - 计时器（分:秒）
  - 🔒/🔓 滚动锁定按钮
- 内容自动滚动到底部（跟随生成进度）
- **生成中可浏览其他产物**：
  - 打开产物抽屉 → 点击文件 → 内容区切为产物查看
  - 顶部流式横幅**不消失**，表示仍在后台生成
  - 生成完成新集后，抽屉自动出现"新"标签
  - 浏览期间实时统计继续更新
- 滚动锁定：
  - 默认自动滚动
  - 点击 🔒 锁定 → 内容区停止自动滚动
  - 再次点击 🔓 恢复
  - 快捷键：`Ctrl+L`

### 3.4 审批面板

- 生成完成后从底部滑入
- 标题行：生成对象 + "请审核并选择版本"
- 描述行：简短说明
- **版本选择标签**：A / B / 混搭
  - 点击切换，对应内容区渲染不同版本
  - 版本 A（默认）：AI 生成的第一个版本
  - 版本 B：AI 生成的备选版本
  - 混搭：自由文本编辑区，可从 A/B 复制内容
- 操作按钮：
  - ✓ 确认选中的版本
  - ✎ 确认混搭（仅在混搭模式显示）
  - ↺ 重新生成
  - ⏭ 跳过剩余，进入下一阶段
  - ✕ 取消

### 3.5 产物抽屉

- 从右侧滑入（280px），半透明遮罩覆盖内容区
- 按阶段分组，显示所有已完成产物
- 新生成的产物带"新"标签 + 淡入动画
- 抽屉底部：文件总数 + 总字数
- 抽屉边缘浮标：有新产品时显示紫色脉动点
- 快捷键：`Ctrl+B`

### 3.6 底部阶段导航

- 6 个阶段标签，一行显示
- 已完成：绿色圆点 ✓
- 当前阶段：紫色底线 | 生成中显示黄色脉动点
- 待开始：灰色圆点 ○
- 点击跳转到该阶段第一个产物
- 右侧快捷操作：▶ 继续 / 📋 文件

## 四、快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+B` | 打开/关闭产物抽屉 |
| `Ctrl+Enter` | 开始生成 |
| `Ctrl+→` | 切换到下一阶段 |
| `Ctrl+←` | 切换到上一阶段 |
| `Ctrl+L` | 生成中锁定/解锁滚动 |
| `Esc` | 关闭抽屉 / 取消生成 |

## 五、设计原则

1. **内容优先** — 导航按需出现，空间最大化给内容
2. **状态一致** — 顶部/底部信息和仪表盘数据统一来源
3. **审批有仪式** — 版本选择是核心决策点，不能缩成小按钮
4. **生成不阻塞浏览** — 后台生成 → 前台浏览，互不干扰
5. **渐进披露** — 仪表盘是入口，产物抽屉是按需细节，内容区是主要阅读区

## 六、技术实现要点

### 前端

- React + TypeScript（现有技术栈）
- 全局状态：`useReducer` 管理 artifacts、generating、curPhase、activeId
- WebSocket 流式内容：复用现有 `useWebSocket` hook
- 产物数据源：项目目录扫描 → 统一 artifacts 数组
- 审批版本：WebSocket `awaitingVersion` 回调，版本数据存入 state
